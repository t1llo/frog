# Competitor screenshots

Public product images of competing Mac menu-bar apps, kept only for a UI design comparison with Frog. They come from official product pages, docs, press kits, GitHub repositories and the Mac App Store listing; nothing was signed in to or paid for. All images belong to their makers.

Saved 2026-11-07. Images wider than 2000 px were downscaled; WebP, AVIF and JPEG were converted to PNG, then all saved as JPEG (quality 85) to keep the repository small.
