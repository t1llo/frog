# Frog 0.1.0 — native macOS preview

A menu-bar writing assistant for macOS 14 and later. Select text, run a rule with a shortcut, and get the result copied and replaced in place.

## Included

- Native SwiftUI interface with light and dark appearances.
- Proofreading, spelling, email polishing, translation, and custom rules with individual shortcuts and provider/model settings.
- OpenAI, Claude, Gemini, OpenAI-compatible endpoints, and Ollama. API keys stay in Keychain.
- Editable JSON configuration import/export, with validation and a backup before replacement.
- Optional local history, disabled by default. No analytics, telemetry, or Frog backend.

## Install

Download **Frog-macOS.zip**, unzip it, and move **Frog.app** to **Applications**. The build supports Apple silicon and Intel. Add a provider in Frog, then grant Accessibility access for selection replacement in other apps. **Try text** works without that permission.

This preview is ad-hoc signed and **not notarized**. If macOS blocks it, use **Open Anyway** in System Settings → Privacy & Security after attempting to open it.

`SHA256SUMS` contains the ZIP's checksum. To verify a download, place both files in the same folder and run `shasum -a 256 -c SHA256SUMS` there.
