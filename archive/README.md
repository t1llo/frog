# Archived prototypes

The user replaced the cross-platform Go/Wails plan with a native SwiftUI macOS application. These files are historical reference, not active build inputs:

- `wails-prototype/`: original Go backend, Svelte frontend, Wails configuration, platform assets, and existing local modifications at the architecture change.
- `xcode-prototype/working-tree/`: the pre-existing `froggy` Xcode project as found on disk.
- `xcode-prototype/index-snapshot/froggy/`: its staged Git snapshot, preserving template Swift/assets/test files that had been deleted from the working tree before this task.
- `partial-go-backend/`: superseded parallel configuration/credential groundwork from commit `c4de894`, preserved without integrating it into the native app.

Ignored generated assets/dependencies may remain locally but are not part of the native app. Do not follow archived product scope or runtime instructions for the active project.
